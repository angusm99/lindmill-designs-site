STEP 3 — TEST LOCALLY
-----------------------
Open index.html directly in Chrome or Edge (double-click it).
The page works as a local file — no server needed for basic testing.


STEP 4 — PUBLISH ON NETLIFY (FREE)
------------------------------------
1. Go to https://netlify.com
2. Sign up free (use your email)
3. On the dashboard, find the drag-and-drop deploy area
4. Drag the entire "lindmilldesigns-site" folder onto it
5. Done! You get a free URL like https://something-random.netlify.app

STEP 5 — CUSTOM DOMAIN (optional, ~R200/year)
-----------------------------------------------
- Buy a domain at Namecheap.com (e.g. lindmilldesigns.com)
- In Netlify → Site settings → Domain management → Add custom domain
- Follow Netlify's instructions — straightforward, takes ~10 minutes


========================================
  QUICK CONTENT EDITS (in index.html)
========================================

CHANGE THE BIO TEXT:
  Search for: "I'm a digital designer specialising in branding"
  Edit the two <p class="about-bio"> paragraphs in the about section.

CHANGE THE EMAIL:
  Search for: thelindamiller@gmail.com
  Replace all instances with the correct address.

ADD/REMOVE A PROJECT TILE:
  In the "project-grid" div, each tile is a <div class="project-tile">.
  Copy an existing tile block and update the onclick, folder name, and label.
  Also add a matching entry in the PROJECTS object in the <script> section.

REMOVE "SOON" BADGE FROM A TILE:
  Delete the <div class="tile-soon">Soon</div> line from that tile.

CHANGE COLOURS:
  At the top of the <style> block, edit the :root CSS variables:
    --navy:  #06102e   (dark background)
    --lime:  #c7ff3e   (green-yellow accent)
    --pink:  #ff3d96   (hot pink)
