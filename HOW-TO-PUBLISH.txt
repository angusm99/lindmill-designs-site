STEP 1 — ADD OR SWAP IMAGES
-----------------------------
Put images inside the "images" folder — each project has its own subfolder.
Name them: 01.jpg, 02.jpg, 03.jpg, … (zero-padded, .jpg or .png or .gif)
The site auto-discovers files up to 50 per folder — just add files and redeploy.

STEP 2 — UPDATE YOUR SOCIAL LINKS
-----------------------------------
Open index.html in any text editor (Notepad, VS Code, etc.).
Search for these placeholder URLs and replace with your real profiles:
  href="https://www.instagram.com/"
  href="https://www.linkedin.com/"
  href="https://www.behance.net/"


STEP 3 — TEST LOCALLY
-----------------------
Open index.html directly in Chrome or Edge (double-click it).
The site works as a plain local file for basic testing.
Gallery images may not load on file:// — use a local server for full testing
(VS Code → right-click index.html → Open with Live Server).


STEP 4 — PUBLISH ON NETLIFY (FREE, easiest)
--------------------------------------------
1. Go to https://netlify.com and sign up free (use your email)
2. On your dashboard, click "Add new site" → "Deploy manually"
3. Drag the entire "lindmilldesigns-site" folder onto the drop zone
4. Done! You get a free URL like https://something-random.netlify.app
5. To update later: drag the folder again — Netlify keeps the same URL

STEP 5 — AUTO-DEPLOY FROM GITHUB (set-and-forget)
---------------------------------------------------
Once you want changes to go live automatically:
1. In Netlify → your site → "Site configuration" → "Build & deploy"
2. Connect to GitHub → choose repo: angusm99/lindmill-designs-site
3. Build command: (leave blank)  Publish directory: /  (root)
4. Every git push to main will now auto-deploy within ~30 seconds


STEP 6 — CUSTOM DOMAIN (optional, ~R200–R350/year)
----------------------------------------------------
- Buy a domain at Namecheap.com or domains.co.za (e.g. lindmilldesigns.com)
- In Netlify → Site configuration → Domain management → Add custom domain
- Netlify guides you through pointing DNS — takes ~10 minutes + up to 1 hour
  for DNS to propagate


========================================
  QUICK CONTENT EDITS (in index.html)
========================================

CHANGE THE BIO TEXT:
  Search for: "I'm a digital designer specialising in branding"
  Edit the two <p class="about-bio"> paragraphs in the About section.

CHANGE THE EMAIL ADDRESS:
  Search for: thelindamiller@gmail.com
  Replace all instances (3 places) with the correct address.

CHANGE COLOURS:
  At the top of the <style> block, edit the CSS variables:
    --navy:  #06102e   (dark navy background)
    --lime:  #c7ff3e   (lime-green accent / wordmark)
    --pink:  #ff3d96   (hot pink / CTA)

ADD AN IMAGE TO A GALLERY:
  Drop a new file into the matching images/ subfolder, numbered next in sequence.
  E.g. if logo-design/ has 01–17.jpg, add 18.jpg and redeploy.

REPLACE A GALLERY THUMBNAIL:
  Overwrite the matching file in images/thumbnails/ (01.gif–12.jpg).
